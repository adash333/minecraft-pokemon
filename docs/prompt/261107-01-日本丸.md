# 日本丸の追加（2026年11月7日）

## プロンプト原文

```text
どんなムービーでも一発で倒せるニッポンマルという刀を作りたいと思います。それは持ってる自分も無限のライフだし、その刀も無限のライフですあ、ちょっと待って
```

```text
どんなムービーじゃなくてモブです。そして左手に持つことでさやを左につけることができ、右、右で横向き斬り、左で縦向き斬りができることがあります
```

```text
画像もお願いします。日本丸は語カナではなく漢字です。
```

```text
右クリック一回でお願いします。
```

```text
マインクラフトの画像に、マインクラフトの画像でお願いします。
```

```text
右手に持たせてください。
```

## 結果

- 刀「日本丸」を戦闘タブに追加。`/give @p minecraftpokemon:nippon_maru` でも入手できる。右手に刀を持ち、三人称では鞘が左腰に見える。
- 左クリック1回で縦斬り、右クリック1回で横斬り。サーバーで斬撃の範囲と遮蔽物を判定し、当たったモブに致死ダメージを与える。手に持っている間は体力が満タンになり、ダメージを無効化する。刀に耐久値はない。
- 通常ビルドに成功。Forge GameTest 5件で、縦斬り、横斬りと壁の遮蔽、出現中のウィザー、エンダードラゴンの部位への攻撃、持ち主と刀へのダメージ無効化を確認した。クライアント画面での表示とマウス操作は未確認。
- Gradle の release タスクで 1.0.26 の JAR を生成し、バージョンと必要なリソースの同梱を確認した。配布先は `build/libs/minecraft-pokemon-1.0.26.jar`。
- 内蔵 imagegen でマインクラフト風のイメージ画像を作り、`output/imagegen/nippon-maru-minecraft.png` に保存した。
