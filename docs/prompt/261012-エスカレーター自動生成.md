# エスカレーター自動生成（2026-10-12）

## 依頼
- エスカレーターを作りたい。
- ブロックを始点と終点の2か所に置くと、終点の高さまでエスカレーターを自動生成してほしい。

## 実装・回答
- 階段型エスカレーターブロックと、2地点を記録・接続する専用アイテムを追加。
- 同一XまたはZ座標、横距離1〜128ブロック、高低差は横距離以下に対応。端点が低ければ下り、同じ高さなら動く歩道。
- 始点・終点に各1個を使用して全区間を生成。途中の既存ブロックや頭上の障害物、設置権限、ロード状態、高さ制限を事前確認し、障害があれば生成せず始点を保持。
- 乗ると自動移動、しゃがむと停止。ブロックごとの右クリックで上り・下りを切替。アイテムを持ってしゃがみながら地面を右クリックすると始点記録を解除。
- 登録、モデル、ブロック状態、日英名称、レシピ、ドロップ、READMEの使い方を追加。
- 配布物：build/libs/minecraft-pokemon-1.0.25.jar。releaseタスク成功によりVERSIONを1.0.24から1.0.25へ1回更新。

## 検証
- Gradle build --offline 成功。release --offline 成功。
- 全リソースJSONの解析と、距離1〜128の全対応高低差について段差が1以下・終点の高さが一致することを確認。
- 初回ビルドはGradleユーザーキャッシュへのアクセス制限で失敗。権限付き実行で成功。
- Minecraftを起動しての実プレイ検証は未実施。
- 指定方針に従い、開始時に存在した自販機・変身・生物関連などの変更と既存配布物も含め全変更を保存する。
