# Minecraft Pokémon Mod 機能追加

- 日付: 2026-08-09

## プロンプト概要

- ミュウが100匹以上になった場合、なついていないミュウを削除する。
- Windows版CurseForgeのMinecraftと `mods` フォルダの場所を確認する。
- 配布JARをVer.6（`1.0.6`）として作成し、以後の配布バージョンを自動更新する。
- ミニリュウを15秒ごとに2匹出現させ、虹色のマンゴーでハクリュウ、カイリューへ順番に進化させる。
- 虹色のマンゴーを食べ物ガチャから排出し、各ポケモン用のモデルと画像素材をJARへ収録する。
- ミニリュウ、ハクリュウ、カイリューをモンスターボールで70%の確率でなつかせる。
- カイリューの目を見えるようにして、よりかわいい外見と飛行能力を追加する。
- 進化ポケモン3段階の合計が100匹以上になった場合、なついていない個体をすべて削除する。
- `/save-prompt` で会話概要を保存し、全変更を `main` へプッシュできるようにする。

## 回答・実施内容

- サーバー全体の読み込み済み個体を数え、100匹目の追加時に未懐き個体だけを削除する処理を実装した。
- CurseForgeの対象フォルダが `C:\Users\adash\curseforge\minecraft\Instances\1.20.1\mods` であることを確認した。
- `VERSION` を唯一のバージョン情報源とし、Gradleの `release` タスクでパッチ番号を1つ増やしてからJARを作る仕組みを追加した。
- ミニリュウ、ハクリュウ、カイリューを1つの進化エンティティとして実装し、進化段階と懐き状態、飼い主をワールドへ保存するようにした。
- 虹色のマンゴーを追加し、食べ物ガチャからもものみと同確率で排出するようにした。
- 組み込みImageGenで3段階のMinecraft向けスキンと虹色のマンゴーを生成し、カイリュー用スキンは大きな目と柔らかい表情へ更新した。
- 捕獲処理を共通化し、ミュウと進化ポケモンを70%の確率でなつかせるようにした。
- カイリューへ飛行ナビゲーション、飛行速度、無重力移動、羽ばたきアニメーション、飼い主への空中追従を追加した。
- READMEへ各機能とバージョン運用を追記し、配布版を `1.0.6` から `1.0.9` まで順番に発行した。

## 検証

- 各変更後にGradleの通常ビルドとリリースビルドを実行し、すべて成功した。
- 最新JARの内部バージョンが `1.0.9` であることを確認した。
- 最新JARにJavaクラス、モデル、翻訳、ミニリュウ・ハクリュウ・カイリュー・虹色マンゴーの画像が含まれることを確認した。
- `git diff --check` でエラーがないことを確認した。
- 更新したグローバル `save-prompt` スキルを公式の `quick_validate.py` で検証し、`Skill is valid!` を確認した。
