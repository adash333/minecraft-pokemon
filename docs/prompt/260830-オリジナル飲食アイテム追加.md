# オリジナル飲食アイテム追加

## 依頼内容

- 添付資料を基に、Minecraft Java Edition 1.20.1 / Forge MODへ「クリーパーコーラ」「メロンパン」「メロンソーダ」を追加する。
- 各アイテムを実際に飲食可能にし、専用の見た目と効果を設定する。
- メロンソーダは一般的なクリームソーダらしく、緑のソーダ、バニラアイス、さくらんぼ、ストローを備えたグラスの見た目にする。
- クリーパーコーラはクラシックな瓶コーラ風にし、クリーパー柄のラベルを付ける。
- クリーパーコーラを飲むと爆発に耐えやすくする。
- 3種類のクラフトレシピを追加し、クリーパーコーラは最終的に全段を `101`（1=ガラス、0=砂糖）とする。
- `/save-prompt` により、会話と作業内容を保存し、現在の全変更を `main` から `origin/main` へプッシュする。

## 対応内容

- `DrinkItem` を追加し、飲むアニメーションと空のガラス瓶を返す処理を実装した。
- クリーパーコーラに満腹度回復、移動速度上昇30秒、耐性 IV 30秒を設定した。
- メロンパンに大きめの満腹度回復を設定した。
- メロンソーダに満腹度回復と跳躍力上昇30秒を設定した。
- 3アイテムをクリエイティブ一覧と食べ物ガチャの景品へ追加し、日本語・英語翻訳、アイテムモデルを登録した。
- 内蔵ImageGenで透明背景のピクセルアートを作成し、32×32テクスチャへ変換した。
  - メロンソーダは喫茶店のメロンクリームソーダ風へ変更した。
  - クリーパーコーラは濃い茶色のコーラ入りガラス瓶と緑のクリーパー柄ラベルへ変更した。
- クラフトレシピを追加した。
  - メロンパン: 中央にスイカ、周囲8マスに小麦。
  - メロンソーダ: スイカの下にガラスを縦に2個。
  - クリーパーコーラ: `GSG / GSG / GSG`（左右列がガラス、中央列が砂糖）。
- READMEへ効果とクラフト方法を追記した。
- 作業ツリーに存在していたハンバーガー、フライドポテト、アイスクリーム、サラダの登録・モデル・テクスチャ、およびローカルプレイヤー用ツインテールキャラクタースキン表示処理と素材も今回の全変更コミットへ含める。
- `VERSION` はリリースタスクにより段階的に更新され、最終版を `1.0.17` とした。`build/libs` の `1.0.10` から `1.0.17` までのJARと、`output/skins` の確認用画像も現在の変更として含める。

## 検証

- 各レシピJSONを `ConvertFrom-Json` で構文検査し、すべて成功した。
- Java 17を指定した `gradlew.bat build` が成功した。
- 各配布版は `gradlew.bat release` で作成した。
- 最終JAR `build/libs/minecraft-pokemon-1.0.17.jar` 内のクリーパーコーラレシピが `GSG / GSG / GSG` であることを確認した。
- 最終JARのSHA-256は `70CD47DF9E103FE98A230FDB3AB39D008A8D020A4758839327BE0D2BD1DCAB61`。
- `git diff --check` で差分エラーがないことを確認した。改行コードに関するGit警告のみ発生した。
