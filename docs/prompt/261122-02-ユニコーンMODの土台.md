# 261122 ユニコーンMODの土台

日付の基準は日本時間（Asia/Tokyo）。

## プロンプト本文（原文）

```text
テニコンの元を作ってください。
```

```text
ユニコーン　mod
```

## 結果

- 既存の Minecraft Java Edition 1.20.1 / Forge MOD に、白い馬の姿に角を付けたユニコーンを追加した。スポーンエッグまたは `/summon minecraftpokemon:unicorn` で出せる。通常の馬と同じようになつかせ、サドルを装備して乗れる。試作版では自然スポーンしない。
- Gradle の `release` が成功し、`VERSION` を 1.0.30 に更新した。[配布用 JAR](../../build/libs/minecraft-pokemon-1.0.30.jar) の整合性、バージョン、描画クラス、日英の翻訳、スポーンエッグのモデルを確認した。ゲーム内での実機動作は未確認。

## 見た目のデザイン

### プロンプト本文（原文）

```text
この赤ちゃんユニコーンみたいなユニコーンの画像にしてください。で、あとカクカクにしてください。大人も美しくしてください
```

添付は会話内の赤ちゃんユニコーンの参照画像。

### 結果

- 参照画像をもとに、赤ちゃんと大人を並べたカクカクのデザイン画像を生成し、会話内で提示した。どちらも白い体、パステルの虹色のたてがみ、金色の角、ピンクのひづめ。赤ちゃんは大きな四角い目と短い脚、大人はすらりとした脚と長いたてがみで描いた。
- 今回の成果物はデザイン画像。ゲーム内のモデルと配布用 JAR は前回の版のまま。

## 人参で成長し、寝返りのあとに乗れる機能

### プロンプト本文（原文）

```text
人参を食べたら大きくなります。あと大人になって寝返りをしたら乗れるようになります
```

### 結果

- 新しく出したユニコーンは赤ちゃん。人参を持って右クリックすると 1 本食べて大人になる。クリエイティブでは人参を消費しない。
- まだなついていない大人を地上で空の手で右クリックすると、横に一回転する。寝返りが終わるとなつき、もう一度右クリックすると乗れる。サドルで操縦できる。以前からなついていた個体には引き続き乗れる。
- Gradle の `release` が成功し、[v1.0.31 の JAR](../../build/libs/minecraft-pokemon-1.0.31.jar) の整合性、バージョン、実装クラスを確認した。ゲーム内での動作は未確認。

## 子どもと大人のゲーム内画像

### プロンプト本文（原文）

```text
画像を出してください大人と子供の。
```

```text
今回の元のです。
```

### 結果

- v1.0.31 のソースを Forge 1.20.1 の開発クライアントで実行し、子どもと大人を撮影用ワールドに並べた。左が子ども、右が大人。[ゲーム内スクリーンショット](../../output/unicorn/unicorn-foal-and-adult-v1.0.31.png)
- 現行モデルは白い体とカクカクした角で、虹色のたてがみはデザイン画像にある。

## 虹色のたてがみとしっぽ、黄色い角、大人の自動乗車

### プロンプト本文（原文）

```text
立てがきをいろんな色にして、しっぽもいろんな色にしてください。あとは角を黄色くして、あとはいいです。
```

```text
とあと登れるようにして、引っくりで背中に乗れるようにしてください。
```

```text
それも大なかにしてください。
```

```text
大人だけが寝返りして、背中に乗れる
```

### 結果

- 子どもと大人のたてがみとしっぽをパステルの虹色、角を黄色にした。[ゲーム内スクリーンショット](../../output/unicorn/unicorn-foal-and-adult-v1.0.32.png)
- 地上でまだなついていない大人を空の手で右クリックすると、寝返りが終わって起き上がったときに近くのプレイヤーを自動で背中に乗せる。子どもには乗れない。Forge の撮影用ワールドで両方の外見、子どもの右クリック、大人の寝返りと自動乗車を確認した。
- Gradle の `release` が成功し、[v1.0.32 の JAR](../../build/libs/minecraft-pokemon-1.0.32.jar) と同梱テクスチャを確認した。
