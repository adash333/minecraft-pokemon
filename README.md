# Minecraft Pokemon Gacha

Minecraft Java Edition 1.20.1 / Forge 用の小さな Mod です。

## 入っているもの

- ワールド初回起動時、スポーン地点近くに 2 つのガチャを自動生成
  - モンスターボールガチャ
  - もものみガチャ
- ガチャを右クリックするとアイテムを入手
- ミュウ風の「ミュウブロック」がスポーン地点近くに出現
- モンスターボールを投げて当てると捕獲判定
  - 70%: 捕獲成功。プレイヤーになつく
  - 30%: 逃げる
- ミュウブロックは地面から自動で浮き上がり、空中を飛んで移動・待機する
- ミュウブロックとミニリュウは、なついていてもプレイヤーから20ブロックより離れる。通常は24〜32ブロック離れた場所に出現し、20ブロック以内に入ると安全な離れた場所へ移動する。安全な出現位置がなければ出現を見送る
- ミュウブロックが100匹以上になると、なついていない個体だけが消える
- もものみをあげるとハートを出して喜ぶ
- もものみをあげたとき、25% の確率で少し大きく進化
- ミニリュウがプレイヤーの近くに15秒ごとに2匹出現
- 食べ物ガチャから「虹色のマンゴー」などの食べ物が出現
- 食べ物ガチャからオリジナル飲食アイテムが出現
  - クリーパーコーラ: 満腹度を少し回復し、30秒間移動速度と耐性 IV が付与される
  - メロンパン: 満腹度を大きく回復
  - アレイパン: 写真の絵を元にした淡い水色のパン。満腹度を6（アイコン3個分）回復し、プレイヤー自身がアレイに変身。満腹でも食べられる
    - F5で姿を確認。持ち物・視点・移動操作はそのまま。体と視点もアレイの大きさになる
    - 変身すると自動で飛行し、変身中は常に飛行を維持。ジャンプで上昇、スニークで下降。着地やジャンプキー2回でも飛行は解除されない
    - 牛乳を飲むと解除。死亡時も解除。変身は再ログイン後も継続
    - 空中で解除した場合は10秒間ゆっくり落下。クリエイティブ・スペクテイター本来の飛行能力は維持
  - メロンソーダ: 満腹度を少し回復し、30秒間ジャンプ力が上昇
- オリジナル飲食アイテムをクラフトテーブルで作成可能
  - メロンパン: 中央にスイカ、周囲8マスに小麦
  - アレイパン: パン・砂糖・ヒスイランを各1個（配置自由）。クリエイティブの「道具と実用品」や `/give @p minecraftpokemon:allay_bread` でも入手可能
  - メロンソーダ: スイカの下にガラスを縦に2個
  - クリーパーコーラ: 左右の列にガラス各3個、中央の列に砂糖3個
- ミニリュウに虹色のマンゴーをあげると、ハクリュウ、カイリューの順に1段階ずつ進化
- ミニリュウ、ハクリュウ、カイリューはモンスターボールで70%の確率でなつく
- なついたハクリュウとカイリューは飼い主を追いかけ、カイリューは翼で空を飛んでついてくる
- ミニリュウ、ハクリュウ、カイリューが合計100匹以上になると、なついていない個体だけが消える

## ビルド方法

このフォルダで Gradle を使ってビルドします。

```powershell
gradle build
```

ビルドできたら、次の jar を CurseForge の `mods` フォルダへ入れます。

```text
build/libs/minecraft-pokemon-<VERSION>.jar
```

## バージョン管理

- 現在のバージョンはルートの `VERSION` ファイルで管理します。
- 確認用の `gradle build` ではバージョンは変わりません。
- 配布版は `gradle release` で作成します。成功するとパッチ番号が1つ上がり、その番号の jar が作成されます。
- バージョンは `1.0.6`、`1.0.7`、`1.0.8` の順で増やします。

## CurseForge で遊ぶ手順

1. CurseForge で Minecraft Java Edition 1.20.1 の Forge プロファイルを作る
2. この Mod をビルドする
3. 出来上がった jar をプロファイルの `mods` フォルダへ入れる
4. 新しいワールドを作る
5. スポーン地点近くにガチャとミュウブロックが出る

## エスカレーター

- 「道具と実用品」から入手、または `/give @p minecraftpokemon:escalator 2`。
- 鉄インゴット6個とレッドストーン1個で2個作成（上段左に鉄、中段は鉄・レッドストーン・鉄、下段は鉄3個）。
- 1個目を置いて始点を設定し、2個目を終点の高さに置くと自動でつながります。2個で全区間を生成できます。
- 始点と終点は同じX座標またはZ座標にしてください。横の距離は最大128ブロックで、高さの差以上必要です。
- 終点が高ければ上り、低ければ下りになります。同じ高さなら動く歩道になります。
- 途中のブロックと頭上2ブロックに障害物があれば、生成せず始点を保持します。
- エスカレーターに乗ると自動移動。しゃがむと止まります。各ブロックを右クリックするとそのブロックの上り・下りを切り替えます。
- エスカレーターを持って、しゃがみながら地面を右クリックすると始点の記録をリセットできます。
